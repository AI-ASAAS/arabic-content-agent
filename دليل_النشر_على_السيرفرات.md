# دليل النشر على السيرفرات (Cloud & Server Deployment Guide)

دليل نشر **منظومة أساس لصياغة المحتوى التسويقي العربي** على أي سيرفر سحابي أو VPS.

---

## 1. النشر عبر Docker Compose (الموصى به)

```bash
git clone https://github.com/AI-ASAAS/arabic-content-agent.git
cd arabic-content-agent
cp .env.example .env   # اختياري: أضف LLM_API_KEY إن أردت مفتاحاً افتراضياً على السيرفر
chmod +x deploy.sh && ./deploy.sh
```

أو يدوياً:
```bash
docker compose up --build -d
```

**الروابط بعد التشغيل:**
- **الواجهة التفاعلية:** `http://SERVER_IP:5180`
- **توثيق API (Swagger):** `http://SERVER_IP:8085/docs`
- **فحص صحة الخادم:** `http://SERVER_IP:8085/api/health`

---

## 2. النشر المباشر عبر Python FastAPI و PM2 (بدون Docker)

```bash
git clone https://github.com/AI-ASAAS/arabic-content-agent.git
cd arabic-content-agent

# تجهيز الخادم الخلفي
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements.txt

# بناء الواجهة الأمامية
cd frontend && npm install && npm run build && cd ..

# التشغيل عبر PM2
npm install -g pm2
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

---

## 3. ربط دومين وتفعيل SSL مجاني (Nginx + Let's Encrypt)

```bash
sudo apt update && sudo apt install -y nginx certbot python3-certbot-nginx
sudo cp nginx-server.conf.example /etc/nginx/sites-available/asaas-agent
sudo nano /etc/nginx/sites-available/asaas-agent   # استبدل your-domain.com بنطاقك
sudo ln -s /etc/nginx/sites-available/asaas-agent /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d your-domain.com
```

*(ملف `nginx-server.conf.example` مهيأ مسبقاً لتعطيل `proxy_buffering` على مسار `/api/` لضمان عمل البث المباشر SSE بسلاسة).*

## المنافذ الافتراضية

| الخدمة | المنفذ | الوصف |
| :--- | :---: | :--- |
